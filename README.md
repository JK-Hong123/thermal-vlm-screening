# Physics first, language last: a falsifiable screening protocol for vision-language models before they are trusted with industrial thermal images

Code, prompts, derived data, raw model outputs and audit logs for the manuscript of the same title (Jeongkyu Hong, University of Seoul; submitted to *Scientific Reports*, 2026).

## What this repository is for

The paper proposes a **screening protocol** for vision-language models (VLMs) on radiometric thermal images: a marker-displacement control, a fact-falsification control (wrong-record and true-record arms) and a synthetic spatial probe, run inside a report pipeline in which deterministic code owns every verdict, severity grade and number. Everything needed to check the paper's numbers without the raw images is here:

## What is deliberately not here

* **No dataset images, crops or temperature matrices.** The AI-Hub industrial thermal CCTV dataset (no. 514) is distributed by AI-Hub under its own terms (domestic applicants; derived data subject to those terms). Per-case radiometric facts (`results/cases_lock/case*/facts.json`) are numerical summaries only. Synthetic probe images are included because they are generated by `src/cascade/probe_spatial.py`.
* No model weights or adapters (train with `src/cascade/train_lora_v2.py` from the dataset).
* No API keys. Gemini runs used the REST interface with the key in `GOOGLE_API_KEY`.

## Layout

```
src/cascade/   pipeline, protocol, controls, judging, audit (see docstrings at the top of each script)
src/eval/      feature extraction, rule and learned-detector baselines
src/data/      manifest, deduplication and split construction
prompts/       pass-1 and pass-2 prompts (Korean) and earlier regimes
agents/        the tool-restricted agent definition used for all frontier subject and judge runs
data/          per-box feature table
results/       derived results, raw model outputs, assembled reports, judge outputs, audit
paper/figs/    figure script
```

Absolute paths of the development machine were replaced by placeholders (`<PROJECT_ROOT>`, `<AIHUB_ROOT>`, `<HF_HOME>`); set them (or edit the constants at the top of each script) before running. Scripts were run with Python 3.11, PyTorch 2.x (CUDA), transformers 5.x, bitsandbytes, scikit-learn, numpy, pandas, matplotlib.

## Reproducing the protocol on another model

1. Build locked cases from your own radiometric frames with `src/cascade/build_cases.py` (facts, crops, marker and displaced-marker renderings).
2. Run pass 1 with `prompts/pass1_blind_v2.txt` on the crop with the marker at the true peak and on the displaced-marker crop (`vlm_diagnose_v2.py`, `gemini_subject.py`, or an agent restricted to reading images and writing answers, as in `agents/vlm-subject.md`).
3. Score with `marker_follow_recompute.py` (kappa against the radiometric peak; fraction following the displaced marker).
4. Run the fact-falsification control in both arms (`build_factpert_tasks.py`, `score_fact_control.py`) and the synthetic probe (`probe_spatial.py`, `probe_api.py`).
5. Only if the model passes, let it fill the descriptive fields and judge the reports against the code-only baseline (`assemble_*.py`, `judge_crossfamily.py`), with the no-image control.
